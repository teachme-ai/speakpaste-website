01

Quick start

  1. Download the DMG, open it, and drag SpeakPaste into /Applications.
  2. Open SpeakPaste and allow macOS to launch the downloaded app.
  3. Grant Accessibility permission in System Settings > Privacy & Security > Accessibility.
  4. Choose Whisper C++ in transcription settings and download a recommended model, or connect a cloud API key.
  5. Click into any text field, hold the dictation shortcut, speak, and release. SpeakPaste types the result at your cursor.

Default docs mention push-to-talk shortcuts such as Option + Shift + D or configured alternatives. Use the shortcut shown in your app settings.

02

Recording modes and methods

Modes

  • Push-to-talk: records only while you hold the shortcut. Best for email, messaging, and precise dictation.
  • Toggle recording: press once to start and once again to stop.
  • Voice activation: uses VAD to detect speech and pauses for hands-free sessions.

Capture methods

  • CPAL: native Rust audio capture into uncompressed WAV. Best reliability and local model compatibility.
  • FFmpeg: advanced shell-based recording for custom audio setups.
  • Browser API: lightweight compressed recording, useful for cloud APIs.
03

04

Transformations and post-processing

SpeakPaste can copy text to the clipboard, type directly at the cursor, and optionally press Return after typing. Transformation pipelines run before output so your dictated text can be cleaned, rewritten, translated, or reformatted.

  • Find & Replace: use exact text or regular expressions for predictable cleanup.
  • AI prompts: send the transcript through OpenAI, Anthropic, Gemini, Groq, Mistral, OpenRouter, or a custom endpoint.
  • Testing workspace: run sample input through a pipeline before applying it to live dictation.
  • Run history: inspect inputs, outputs, step-by-step results, and errors for every transformation run.
05

Recordings and history

  • Review past recordings with transcript status, timestamps, and embedded audio playback.
  • Open the local database folder from the app when you need direct access to stored audio files.
  • Search history, bulk transcribe older clips, bulk delete recordings, or copy selected transcripts with a custom template.
  • Use placeholders such as {{recordedAt}} and {{transcript}} to compile journal-style or meeting-note exports.
06

Preferences, privacy, and updates

Preferences

  • Launch SpeakPaste automatically at login.
  • Keep configuration windows always on top while editing workflows.
  • Configure sound effects, bitrates, sample rates, model paths, API keys, and shortcuts.

Privacy

  • Local engines keep voice audio and raw transcripts on your Mac.
  • Cloud engines are optional and require user-provided credentials.
  • Opt-in analytics exclude voice audio, transcript content, API keys, and account identities.
07

Troubleshooting

macOS says Accessibility is enabled, but typing still fails

Remove SpeakPaste from Privacy & Security > Accessibility, add it again from /Applications, enable the toggle, then restart SpeakPaste.

Shortcuts are delayed or unreliable in the background

Switch the recording method to CPAL. Native Rust capture avoids macOS AppNap delays that can affect browser-based recording.

Local model will not load

Use whisper.cpp-compatible .bin, .gguf, or .ggml files. PyTorch .pt model files are not supported by the local engine.

Browser API recordings will not transcribe locally

Install FFmpeg or use CPAL. Local Whisper engines expect WAV input, and FFmpeg handles conversion from compressed browser recordings.

🛡️ macOS says "unidentified developer"? Here's the fix. ▾

Because SpeakPaste is distributed outside the Mac App Store, macOS Gatekeeper may block it. This is normal for apps distributed directly by the creator. There are two options:

Option A — One-command terminal fix (recommended)

After moving SpeakPaste to your Applications folder, run this in Terminal:

xattr -d com.apple.quarantine /Applications/SpeakPaste.app

Option B — Right-click to open

Right-click (or Control-click) the app in Finder and choose Open. Click Open again in the confirmation dialog. This only needs to be done once.
